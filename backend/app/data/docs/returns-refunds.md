# Returns and Refunds Policy

## Return window
Unused items can be returned within 30 days of delivery for a full refund. Items must include original tags. Gold and platinum loyalty members have an extended 60 day return window.

## Fit and sizing returns
Apparel and footwear that does not fit can be exchanged for a different size at no cost within the return window. Return shipping labels for size exchanges are free.

## Refund processing
Refunds are issued to the original payment method within 5 business days after the returned item is received and inspected. Store credit refunds are instant.

## Non-returnable items
Used stoves and fuel canisters cannot be returned for safety reasons, unless they are defective. Gift cards are non-refundable.
